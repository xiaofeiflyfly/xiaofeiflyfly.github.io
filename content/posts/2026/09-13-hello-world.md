# 你好，世界：这个博客上线了

经过一个下午的折腾，这个博客终于上线了。第一篇文章，按照国际惯例从 Hello World 开始——顺便聊聊这个博客本身是怎么搭起来的。

## 为什么自己写生成器

市面上有 Hugo、Hexo、Astro 一大堆现成的静态博客框架，但我最终还是选择了自己写一个，大约 500 行 Python。灵感来自 [Armin Ronacher 的博客](https://lucumr.pocoo.org)（Flask 的作者），他的博客就是用一个自研的小生成器驱动的，架构非常干净：

- **内容即文件**：文章放在 `content/posts/2026/09-13-hello-world.md`，日期编码在路径里，frontmatter 只有 `tags` 和 `summary` 两个可选字段，标题就是正文第一个 H1。打开文件直接写，没有任何元数据仪式感。
- **URL 即路径**：`/2026/9/13/hello-world/`，去零格式，稳定且可读。
- **零前端框架**：没有 React 也没有 Vue，纯静态 HTML 加一份手写的 CSS，加载飞快。

自己写的好处是排版细节完全掌控——这对中文博客尤其重要。

## 为中文做了哪些适配

大部分静态博客生成器是英文世界的产品，直接拿来写中文会踩不少坑。这个生成器做了几件事：

### 中英文之间自动加空格

汉字和拉丁字母之间插入一个空格，排版会舒服很多。比如"使用Python写代码"会自动渲染成"使用 Python 写代码"。这个处理在渲染层完成，写作时完全不用管。

### 行高与列宽

中文的 x-height 特性与拉丁文不同，正文行高从英文习惯的 1.5~1.7 提高到了 1.9，列宽控制在每行约 40 个汉字，这是中文阅读最舒适的区间。

### 代码注释的中文字体回退

代码块用等宽字体，但注释里的中文会回退到系统中文字体，不会出现豆腐块：

```python
def hello(name: str) -> str:
    """向读者问好——中文文档字符串正常渲染。"""
    return f"你好，{name}！欢迎来到我的博客。"


if __name__ == "__main__":
    # 循环打印前三个问候语
    for i in range(3):
        print(hello(f"访客 {i + 1}"))
```

### 标点与断行

正文使用 `text-align: justify` 配合 `line-break: strict`，中文标点不会出现在行首，两端对齐也更整齐。小屏幕上会自动切回左对齐，避免窄列出现大片空白。

## 暗色模式

跟随系统设置自动切换，夜间阅读不刺眼。颜色全部走 CSS 变量，一套代码两套主题。
